## Executive Summary
This project implements an end-to-end artificial intelligence system capable of monitoring, classifying, and reporting parking slot occupancy status (Vacant vs. Occupied) in real-time using surveillance camera feeds. Using the benchmark **PKLot dataset**, individual parking slot patches were extracted across diverse environmental conditions (sunny, rainy, cloudy). A deep Convolutional Neural Network (CNN) was trained and evaluated against rigorous classification metrics, including accuracy, precision, recall, F1-score, and confusion matrix analysis. The trained system is packaged into an interactive **Streamlit dashboard** that delivers live visual overlays (green for vacant, red for occupied), automated space counting, occupancy percentage tracking, and an interactive slot calibration tool.

---

## 1. Introduction & Problem Statement
Urban vehicular congestion poses major economic, environmental, and public health challenges. Studies consistently show that up to 30% of traffic in urban business districts is generated by motorists cruising in search of available parking spaces. Traditional parking monitoring solutions rely on hardware sensors (such as ground ultrasonic, infrared, or inductive loops) embedded in each parking stall. While functional, these physical sensor networks incur prohibitive installation costs, frequent mechanical failure, battery degradation, and vulnerability to severe weather conditions.

### Objectives:
1. Develop an image/video processing pipeline using Python and OpenCV to segment predefined parking space regions of interest (ROIs).
2. Train a binary deep learning classifier to distinguish between `Empty` (Vacant) and `Occupied` parking slots.
3. Conduct class-wise evaluation utilizing precision, recall, F1-score, accuracy, and confusion matrix analysis.
4. Deploy an intuitive, real-time web dashboard using Streamlit to present live camera feeds, occupancy statistics, and slot calibration tools.

## 2. Dataset Description & Preprocessing
The model is trained on the benchmark **PKLot dataset** (v4 416x416 Roboflow Accurate Model):
- **Provider:** Universidade Federal do Parana (UFPR)
- **License:** Creative Commons Attribution 4.0 (CC BY 4.0)
- **Total Surveillance Images:** 12,416 full parking lot camera frames.
- **Weather Variations:** Sunny (harsh shadows, high contrast), Cloudy (diffuse light, low contrast), Rainy (surface water reflections, windshield refraction).
- **Annotation Format:** YOLO PyTorch format with normalized coordinates `[class_id, x_center, y_center, width, height]`.
  - `Class 0`: `space-empty` (Vacant)
  - `Class 1`: `space-occupied` (Occupied)

### Patch Extraction & Balancing:
Surveillance camera frames were parsed to crop individual parking slot patches. A balanced dataset of 12,000 slot patches was organized into three standard splits:
- **Training Set:** 8,000 patches (4,000 Empty, 4,000 Occupied)
- **Validation Set:** 2,000 patches (1,000 Empty, 1,000 Occupied)
- **Test Set:** 2,000 patches (1,000 Empty, 1,000 Occupied)

Each patch is standardized to 64x64 pixels and normalized using ImageNet channel statistics ($\mu = [0.485, 0.456, 0.406]$, $\sigma = [0.229, 0.224, 0.225]$). Training data is augmented with random horizontal flips and color jitter (brightness and contrast).

## 3. System Architecture & Model Design

```
+-----------------------------------------------------------+
|             Surveillance Camera Stream (CCTV)             |
+-----------------------------+-----------------------------+
                              |
                              v
+-----------------------------------------------------------+
|          Slot ROI Segmentation (slots_config.json)         |
+-----------------------------+-----------------------------+
                              |
                     Batch Crop (64x64)
                              |
                              v
+-----------------------------------------------------------+
|             Deep CNN Classifier (PyTorch)                 |
|             Conv2D -> BatchNorm -> ReLU -> MaxPool        |
|             Adaptive Pooling -> Dense -> Dropout          |
+-----------------------------+-----------------------------+
                              |
                     Softmax Probabilities
                              |
                              v
+-----------------------------------------------------------+
|                   Streamlit Web Dashboard                 |
|   - Green (Vacant) & Red (Occupied) Visual Bounding Boxes |
|   - Real-time Counters: Available, Occupied, Total, Rate  |
|   - Performance Analytics & Confusion Matrix Display      |
+-----------------------------------------------------------+
```

### CNN Architecture (`ParkingSlotCNN`):
- **Input:** $64 \times 64 \times 3$ RGB slot patch
- **Block 1:** Conv2D (32 filters, $3 \times 3$, padding 1) + BatchNorm + ReLU + MaxPool ($2 \times 2$) $\rightarrow 32 \times 32 \times 32$
- **Block 2:** Conv2D (64 filters, $3 \times 3$, padding 1) + BatchNorm + ReLU + MaxPool ($2 \times 2$) $\rightarrow 16 \times 16 \times 64$
- **Block 3:** Conv2D (128 filters, $3 \times 3$, padding 1) + BatchNorm + ReLU + MaxPool ($2 \times 2$) $\rightarrow 8 \times 8 \times 128$
- **Block 4:** Conv2D (128 filters, $3 \times 3$, padding 1) + BatchNorm + ReLU + AdaptiveAvgPool ($4 \times 4$) $\rightarrow 4 \times 4 \times 128$
- **Classifier:** Flatten $\rightarrow$ Dense (128 units, ReLU) $\rightarrow$ Dropout ($p=0.3$) $\rightarrow$ Dense ($2$ units)

## 4. Training Methodology & Hyperparameters
- **Loss Function:** Categorical Cross-Entropy Loss
- **Optimizer:** Adam Optimizer ($\text{lr} = 0.001$, weight decay $= 10^{-4}$)
- **Learning Rate Scheduler:** `ReduceLROnPlateau` (factor $= 0.5$, patience $= 2$)
- **Batch Size:** 64
- **Epochs:** 10 with model checkpointing saving the best validation weights.

---

## 5. Evaluation & Performance Analysis
The model is tested on an independent test partition of 2,000 parking slot patches. Evaluated metrics include:
- **Accuracy:** Percentage of correctly identified slots.
- **Precision:** $\frac{TP}{TP + FP}$ — Ensures vacant spaces are not falsely labeled as occupied.
- **Recall:** $\frac{TP}{TP + FN}$ — Ensures occupied spaces are never mistakenly reported as free.
- **F1-Score:** Harmonic mean of precision and recall.
- **Confusion Matrix:** True Positive, True Negative, False Positive, False Negative distribution.

## 6. Streamlit Dashboard Features
The application interface provides:
1. **Live Camera Feed Analysis:** Inspect sample PKLot parking lot scenes across Sunny, Rainy, and Cloudy conditions, or upload custom images.
2. **Occupancy Counters:** Displays Total Slots, Available Slots, Occupied Slots, and dynamic Occupancy Rate percentage.
3. **Interactive Slot Table:** Real-time filterable breakdown of each parking space ID, status, and prediction confidence.
4. **Model Performance Hub:** Displays the Confusion Matrix heatmap and training loss/accuracy trajectories.
5. **Slot Calibration Tool:** Allows operators to define and export new slot layouts (`slots_config.json`) for new camera perspectives.
